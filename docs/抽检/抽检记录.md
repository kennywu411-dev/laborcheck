# 标准答案抽检记录

## 方法

从评测集 v1 的每个（主题，题型）组中分层随机抽取 1–3 题，共 69 题（抽样种子 7，样本见 `spotcheck-sample.jsonl`）。
复核方式为独立复算：复核人只拿到题面，不看标准答案和规则引擎代码，依据官方条文原文和城市数据文件重新作答，再与标准答案逐题比对（判断题比结论，计算题按该题误差容忍比较，改写题比结论和改写后数值是否满足约束）。
